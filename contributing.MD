# Contributing & Commit Guidelines

## Git Commit Naming Convention
All commits MUST follow this exact format:
`<type>: <what changed> - <why it matters>`

### Allowed Types:
- `feat:` New features or UI components
- `fix:` Bug fixes
- `docs:` Documentation updates (README, Charter, Go-Live note)
- `style:` Layout adjustments or CSS styling
- `test:` QA test cases or mock dataset updates

### Examples:
- `feat: add order status lookup function - enables tracking by order ID`
- `docs: update CONTRIBUTING.md - sets up commit rules for team`

## Rules of Engagement
- Tasks on the project board must be updated on the exact day work is completed.
- No single task should exceed 4 hours of work.
- Zero visible activity for 24+ hours will trigger an internal team check-in.
